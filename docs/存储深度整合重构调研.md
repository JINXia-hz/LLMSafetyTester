## 0. 判断框架：数据到底需要什么

把全部持久化状态按**本质需求**分五类，每类的正确形态不同：

| 类别 | 本质需求 | 正确形态 | 现状形态 |
|---|---|---|---|
| 可变权威状态 | 事务、并发安全、崩溃恢复 | SQLite 表（单事务写） | R✅已库化 / tasks❌ / plans❌ / tickets❌ |
| append-only 事件流 | 只增、时序、按 key 聚合查询 | SQLite 表 + 索引 | gazette❌ / trials❌（jsonl+索引双写） |
| 派生缓存 | 可重建 + 失效键 | 表或文件皆可，但生命周期要统一 | elo_cache❌（json+手写锁）/ predictors✅（文件合理） |
| 大块产物（blob） | 人读、流式 tail、体积大 | **文件永远是真相** | 报告/attack_results/progress✅ 保持文件 |
| 进程内并发原语 | 锁、条件变量、闭包回调 | **永远内存，不是存储问题** | bus 订阅 / confirm 闭包✅ 保持内存 |

第一轮的问题：把第 1、2 类留在了文件形态（用锁模拟事务），又为第 3、4 类在 DB 侧造了兼容层。

### D. 内存态判定（audit 长期档"13 处"逐个裁决）

| 状态 | 裁决 | 依据 |
|---|---|---|
| `_TICKETS`（封驳令） | **落库**（安全修复） | 8 字段纯数据；TTL 即过期条件 |

### E. 非原生实现（从流程需要重设计，不是 1:1 替代）

1. **run 发现靠文件嗅探**（RUN_ARTIFACTS 九种文件 exists）——runner 明知自己在创建什么，却让读方猜。理想：runner 事务化写 runs 行（含产物清单/状态），文件嗅探只留 reindex 修复工具。
2. **task 终态靠 meta.json mtime 对账**——task_manager 直接持有状态，应直接写行。
3. **gazette 搜索靠 500 文件全文读 + SigCache + 文本缓存**——SQL 一句话（66 行事件，LIKE 足够）；`_load_gazette_texts`、planner 的 50-plan 重放循环全删。
4. **thresholds 经 subprocess CLI + `_FALLBACK_THRESHOLDS` 复制体 + TTLCache**（review.py:36-54）——control 实际已直接 import llmsec 四处，纯常量 import 没有隔离收益。
5. **invoker 启发式解析 CLI stdout JSON**（`res.json`）——fork 走 contract 后消失。
6. **isolation monkey-patch 16 常量 + AST 白名单 23 条**——理想：storage 持路径上下文对象，isolation 缩成 swap 上下文 + 日志 handler 切换（唯一不可替点）；守卫只拦"重绑集"。代价：~15 处测试 monkeypatch 改造。
7. `list_workspaces` 每次全目录 du——runner 产物体积无法从 db 得知，保留但可增量维护。

## 2. 目标架构（native 化终态）

```
output/state/
  results.db      R 真相（observations/runits/rmodels）
                  + elo_cache 派生表（事务化，fingerprint 命中键）      ← A5
  catalog.db      runs / trials / tasks（三者皆 db 真相，文件只存产物）   ← A1/A2/E1/E2
                  + control 侧表：gazette_events / plans / tickets /
                    plan_queue / workspaces / env_snapshots             ← A9/D
文件（永真，不入库）：报告/树/md、attack_results.jsonl、progress.jsonl、
                    .log、predictors pkl、cluster pkl、.env
删除的机器：_file_lock 家族、AtomicIndexStore、control locks（除 .env）、
           _migrate_legacy/双格式分支、meta.json、trials.jsonl、三份 _index.json、
           reconcile（降级为 reindex）、SigCache×2、thresholds CLI
```

边界原则不变：control 仍不 import llmsec 内部——`storage.contract` 扩展出 control 侧表的 DAO 与 `rstore.clone/backup`；AST 守卫继续强制。
